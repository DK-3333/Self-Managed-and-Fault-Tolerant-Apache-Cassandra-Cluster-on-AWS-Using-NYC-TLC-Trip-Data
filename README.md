# Self-Managed-and-Fault-Tolerant-Apache-Cassandra-Cluster-on-AWS-Using-NYC-TLC-Trip-Data
This project presents the design, deployment, and administration of a self-managed Apache Cassandra distributed database cluster on AWS EC2 using the NYC TLC Yellow Taxi Trip Records as a realistic event-based workload.
